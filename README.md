# ETGAH Robotics Masterclass

This repository contains the learning tasks and project structure for the ETGAH Robotics Masterclass.

## Masterclass Link

- Official course: https://www.etgah.com/en/masterclass/ros2-robotics-arabic

## Structure

- `Task-01Programming for Robotics/` - Programming exercises and starter project files

## Environment

Developed and tested using the ETGAH Virtual Workspace.

## Getting Started

1. Open the task folder for the relevant lesson.
2. Read that task's README.
3. Implement the required code in the `src/` directory.
4. Run and validate the project using the instructions provided in the task files.
